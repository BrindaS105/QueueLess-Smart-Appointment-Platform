# Feature Prioritization – QueueLess

| Feature | Priority | Reason |
|---|---|---|
| Appointment booking | High | Core user need |
| Token generation | High | Booking identification |
| Queue position | High | User visibility |
| Status tracking | High | Appointment management |
| Search bookings | Medium | Faster discovery |
| Status filters | Medium | Better organization |
| Cancellation | High | Booking flexibility |
| SMS reminders | Low for MVP | Requires external service |
| Real-time queue | Low for MVP | Requires backend |
| Online payment | Low for MVP | Requires payment integration |

## MVP Strategy
Focus on booking, token generation and status tracking.

## Future Strategy
Introduce notifications and real-time queue management
after validating the core experience.
