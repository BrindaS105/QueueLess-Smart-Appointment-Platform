# Product Requirements Document – QueueLess

## Product Overview
QueueLess is a lightweight appointment and queue management prototype.

## Problem
Customers may have difficulty booking appointments and understanding
how long they need to wait.

## Product Goal
Provide a simple booking workflow and appointment status visibility.

## Target Users
- Customers
- Service providers
- Appointment administrators

## Functional Requirements
- Create appointment bookings.
- Select service.
- Choose appointment date and time.
- Generate booking token.
- Display queue position.
- Search bookings.
- Filter booking statuses.
- Update appointment status.
- Cancel bookings.
- Display booking statistics.

## Non-Functional Requirements
- Responsive design.
- Simple navigation.
- Fast interaction.
- Local data persistence.

## MVP Scope
Appointment creation, token generation, basic queue tracking
and status management.

## Out of Scope
- Real-time service integration.
- Payment processing.
- SMS delivery.
- Multi-device synchronization.

## Success Criteria
A user can create a sample appointment and track its status
from the dashboard.
