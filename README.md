# QueueLess – Smart Appointment and Queue Management

## Overview
QueueLess is a front-end prototype that allows users to book
sample appointments and track their queue status.

## Problem Statement
People may spend unnecessary time waiting for services because
appointment scheduling and queue visibility can be limited.

## Proposed Solution
QueueLess provides an appointment booking workflow and a
dashboard for tracking sample bookings.

## Features
- Book appointments
- Select service, date and time
- Generate appointment tokens
- View queue positions
- Search bookings
- Filter by status
- Update appointment status
- Cancel appointments
- View booking statistics
- Store data using Local Storage

## Technology
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Open the QueueLess folder.
2. Double-click index.html.
3. Use Google Chrome to access the prototype.

## Product Metrics
- Total bookings
- Waiting appointments
- Appointments in service
- Completed appointments
- Cancellation count

## Limitations
This is a browser-based demonstration.
It does not provide real-time queue updates, actual service
provider integration or verified appointment availability.
